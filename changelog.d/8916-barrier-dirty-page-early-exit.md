- **perf (ECS round 4, −14% on `codehz/ecs` "5k entities: 3 commands each + sync": 4.14 → 3.55 ms/op, each step 15/15 paired runs):**
  - **gc:** an inline-slot store onto the page the one-entry dirty-page cache already holds returns right after the SATB prologue, skipping both the parent and the child classification (the cache's invariant — cached ⟹ recorded in `DIRTY_OLD_PAGES` and stamped dirty — already covers the store). Counted under `BarrierTraceCounter::DirtyPageCacheHits`.
  - **codegen:** `arr.some(capturelessArrow)` runs as an inline loop with a direct call of the arrow's body (rooted receiver re-read per element, forwarded heads through the new `js_array_live_head`, holes skipped, `true`/`false` decided inline); `js_array_some_captureless` stays the fallback for receivers the loop does not admit.
  - **runtime:** `Map` lookups run an always-inlined numeric lane (small-map bit-identity scan or the dense integer range table) ahead of the outlined general `find_key_index`; `Map` dense integer keys decide with one `as u32` round trip; small `Set` (≤ 8) number lookups scan the members before the two-hash side-table; `pop()` on an empty plain array answers from the header fast path; `length = 0` on an all-pointer array re-arms its layout in one registry pass.
  - **driver:** module-level `const` literals (`export const MAX = 1023`) fold into their reads after the whole transform phase and before codegen, so one-line predicates comparing against them earn their typed clones without changing any cross-module inlining decision.
